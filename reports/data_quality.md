# Data quality report

Run `python scripts/clean_data.py` to generate `reports/generated/data_quality.json`. On the supplied file, the observed results were 885,129 source rows and 885,129 retained rows; zero rows were excluded for invalid timestamps, event type, price, product ID, or user ID. The extract spans 2020-09-24 11:57:06 UTC through 2021-02-28 23:59:09 UTC. Missing values were: category_code 236,219; brand 212,364; user_session 165. There were 1,284 rows participating in exact duplicate groups; they were investigated and retained because the source has no event identifier to establish that repeated records are errors. Event counts were 793,748 views, 54,035 carts, and 37,346 purchases. The cleaning script parses timestamps as UTC, validates event type and nonnegative numeric price, requires product and user identifiers for event-level analytics, and retains rows with missing session/category/brand. Invalid data may overlap across reason counts; excluded row count is the union and is therefore not the sum of reason counts. Generated JSON/CSV results are not checked into version control.
